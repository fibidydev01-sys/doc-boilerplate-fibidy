# Apa Itu Fibidy?

Fibidy adalah platform all-in-one untuk UMKM Indonesia. Satu dashboard untuk toko online, kasir, manajemen stok, dan laporan penjualan.

## Fibidy Bukan Marketplace

Fibidy **bukan** marketplace seperti Shopee atau Tokopedia. Kami tidak menjual produkmu, tidak membandingkannya dengan produk lain, dan **tidak mengambil komisi** dari setiap transaksi.

| Aspek | Marketplace | Fibidy |
|---|---|---|
| Komisi penjualan | Ada (5–20%) | **Tidak ada** |
| Produk dibandingkan | Ya | Tidak |
| Pelanggan checkout | Di platform | Via WhatsApp/QRIS |
| Biaya langganan | Tidak ada | Rp 0 – Rp 149.000/bulan |

## Bagaimana Cara Kerjanya?

1. Kamu buat toko online dengan 41 kategori bisnis
2. Pelanggan lihat produk di `namamu.fibidy.com`
3. Pelanggan hubungi kamu via WhatsApp
4. Pembayaran via QRIS/transfer di luar platform

## Siapa yang Cocok?

Warung, salon, coffee shop, laundry, bengkel, fashion — 41 kategori bisnis tersedia.
