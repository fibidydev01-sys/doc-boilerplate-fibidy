# Fibidy Bukan Marketplace

Fibidy adalah platform toko online untuk UMKM, **bukan marketplace**.

## Apa Bedanya?

| Aspek | Marketplace | Fibidy |
|---|---|---|
| Komisi penjualan | Ada (5–20%) | **Tidak ada** |
| Produk dibandingkan | Ya | Tidak |
| Pelanggan checkout | Di platform | Via WhatsApp/QRIS |
| Biaya langganan | Tidak ada | Rp 0 – Rp 149.000/bulan |
| Data pelanggan | Dikelola platform | Sepenuhnya milikmu |

## Bagaimana Transaksi Terjadi?

1. Pelanggan melihat produk di toko online kamu
2. Pelanggan menghubungi kamu via WhatsApp
3. Kamu dan pelanggan sepakati harga & pembayaran
4. Pembayaran via QRIS atau transfer bank
5. Kamu catat transaksi di Kasir (opsional, untuk pembukuan)

**Fibidy tidak pernah memegang uang transaksi.** Semua pembayaran terjadi langsung antara kamu dan pelanggan.
