# Sosial Media

## Mengapa Sosial Media Itu Penting?

> **Pelanggan ingin melihat toko-mu di platform yang mereka gunakan sehari-hari.** Instagram, TikTok, Facebook — di sinilah pelanggan menghabiskan waktu. Menghubungkan sosial media juga membangun kredibilitas: toko dengan akun aktif terlihat lebih "nyata".

## 13 Platform yang Didukung

| Platform | Cocok Untuk |
|---|---|
| Instagram | Produk visual, fashion, makanan, lifestyle |
| Facebook | Komunitas, group, event |
| TikTok | Konten viral, produk kreatif, edukasi |
| YouTube | Video tutorial, review produk, branding |
| Twitter / X | Update cepat, interaksi pelanggan |
| Threads | Diskusi ringan, branding personal |
| WhatsApp | Chat langsung, customer service |
| Telegram | Komunitas, broadcast, group chat |
| Pinterest | Inspirasi visual, produk dekorasi |
| LinkedIn | B2B, jasa profesional, networking |
| Behance | Portfolio desain kreatif |
| Dribbble | Portfolio desain UI/UX |
| Vimeo | Video portfolio berkualitas tinggi |

## Aturan

> <IconWarning /> **Minimal 1 platform wajib diisi saat setup awal.**

Platform yang diisi tampil di footer toko online. Kamu bisa menghubungkan beberapa platform sekaligus.

## Tips Memilih Platform

| Jenis Bisnis | Platform yang Disarankan |
|---|---|
| Kuliner / Warung | Instagram, TikTok, WhatsApp |
| Fashion / Retail | Instagram, TikTok, Pinterest |
| Laundry / Salon | Instagram, Facebook, WhatsApp |
| Event / Fotografi | Instagram, YouTube, Behance |
| B2B / Jasa Profesional | LinkedIn, Instagram, WhatsApp |

> <IconTip /> **Lebih baik 3 platform aktif daripada 7 platform yang tidak pernah diupdate.** Akun tidak aktif bisa mengurangi kepercayaan pelanggan.

## Cara Mengatur

1. Buka `/dashboard/settings?section=social`
2. Isi URL profil sosial media
3. Klik "Simpan"

## Troubleshooting

| Masalah | Solusi |
|---|---|
| Link sosial tidak muncul di footer | Pastikan URL sudah diisi dan disimpan |
| Link tidak bisa diklik | Cek format URL — harus lengkap dengan `https://` |
| Error minimal 1 platform | Isi setidaknya satu platform sebelum menyimpan |
