# 25 Variasi Template Hero

## Mengapa Ada Banyak Template?

> **Setiap bisnis itu unik.** Toko fashion butuh tampilan yang berbeda dari laundry, dan laundry berbeda dari salon. 25 template memberikan fleksibilitas tanpa kerumitan — tinggal pilih, lihat pratinjau, publish.

## Template 1–3 — Gratis

Minimalis dan clean, cocok untuk semua jenis toko.

| Template | Karakteristik | Cocok Untuk |
|---|---|---|
| **Template 1** | Hero dengan gambar latar + teks di tengah | Semua jenis toko, tampilan klasik |
| **Template 2** | Hero dengan gambar di kiri, teks di kanan | Menonjolkan produk/foto |
| **Template 3** | Hero dengan teks di kiri, gambar di kanan | Mengutamakan pesan branding |

> <IconTip /> **Tiga template ini sudah mencakup 90% kebutuhan tampilan toko UMKM.** Pilihan lebih banyak baru diperlukan saat bisnis sudah lebih matang.

## Template 4–12 — Starter

Lebih banyak variasi, efek visual, layout hero berbeda.

| Template | Karakteristik |
|---|---|
| **Template 4** | Overlay gradasi dengan CTA bold |
| **Template 5** | Animasi text reveal |
| **Template 6** | Split layout dengan efek parallax |
| **Template 7** | Full-width image dengan CTA di bawah |
| **Template 8** | Grid layout untuk multiple CTA |
| **Template 9** | Carousel produk unggulan di hero |
| **Template 10** | Video background (placeholder) |
| **Template 11** | Testimonial quote di hero |
| **Template 12** | Countdown untuk promo berbatas waktu |

## Template 13–25 — Business

Full creative control — kombinasi elemen lanjutan, efek, dan layout kompleks.

> <IconWarning /> **Template 13–25 membutuhkan paket Business untuk dipublish.** Pratinjau tetap bisa dilihat di Studio meski paket belum Business.

## Memilih Template yang Tepat

| Jenis Bisnis | Template yang Disarankan |
|---|---|
| Warung / Kuliner | 1, 4, 6 — fokus pada gambar makanan |
| Salon / Kecantikan | 2, 5, 8 — menonjolkan transformasi |
| Fashion / Retail | 3, 7, 9 — koleksi produk |
| Laundry / Jasa | 1, 4, 10 — kemudahan & kepercayaan |
| Event / Fotografi | 6, 11, 12 — portfolio & promo |

## Cara Mengetahui Template yang Sedang Aktif

1. Buka Studio
2. Lihat tanda centang di drawer template
3. Nama template tampil di area pratinjau

## Troubleshooting

| Masalah | Solusi |
|---|---|
| Template tidak sesuai pratinjau | Refresh halaman Studio |
| Template tidak bisa dipublish | Cek paket langganan |
| Pratinjau lambat loading | Koneksi internet lambat — tunggu sebentar |
